# DN倒计时工具 · 使用说明

两个悬浮窗：一个是**增益 / 减益状态倒计时**，另一个是 **Boss 技能倒计时**，配中文语音播报。

只读游戏发到本机的网络包，不注入、不修改游戏、不改存档，**不向任何服务器发送数据**。

---

## 一、运行环境

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11，64 位 |
| 权限 | **管理员**（读取网卡数据必须提权，每次启动会弹 UAC） |
| 抓包组件 | **Npcap**（需要单独安装，见下） |
| 游戏 | 需与工具在同一台机器上运行 |

---

## 二、第一次使用

**1. 安装 Npcap**

工具本身不带安装包。到 Npcap 官网下载安装（`npcap-1.xx.exe`），安装时保持默认选项即可。

装完可以打开工具的 **设置 → Npcap 库与驱动路径** 查看是否识别到。也可以在那一页手动指定 `wpcap.dll` 的位置。

> 如果设置页的「安装随包 Npcap」按钮提示找不到安装文件，就是当前这个包没带安装程序，按上面的方式自己装一次就行。

**2. 解压启动**

把压缩包解压到任意**你自己有写权限**的目录（比如 `D:\DN倒计时工具\`），双击 `dn-countdown.exe` 或 `Start-Portable.bat`，UAC 弹窗点「是」。

不建议放在 `C:\Program Files` 下面——后续想换版本、看日志都会多一层权限麻烦。

**3. 先开工具，再进副本**

打开工具 → 点 **「开始统计」**(依赖游戏进程,需要先打开游戏才能点击统计) → 再进副本。

> 这一条很关键：**进副本前就开始统计**，副本靠"进本那一瞬的地图包"识别，最准。
> 进了本才点也能用，但副本只能靠"你正在打的 Boss"反推，偶尔会慢一拍，或者第一关只出一个 Boss 时认不出来。

---

## 三、两个悬浮窗

启动统计后，两个窗口会自动出现：

- **Buff / Debuff 状态悬浮窗**：队伍增益、减益、增伤减抗的剩余时间
- **Boss 技能倒计时悬浮窗**：Boss 关键技能的"预计已好"时间

操作：

- 按住窗口顶部拖动位置，**位置会自动记住**
- 关掉窗口后可以用快捷键 `Alt+F12` 一键重新拉起（统计 + 悬浮窗一起开）
- **统计面板上的「悬浮窗设置」** 里可以改：显示哪些 Buff、横向条目还是图标、字号颜色透明度、每列条数、显示哪些 Boss 技能
- 同一页右上角有 **导出 / 导入**，换电脑时把设置搬过去

## 四、语音播报

入口在统计面板的 **「语音播报」** 按钮。

**巢穴多选**：黑龙经典 / 黑龙硬核 / 沙龙硬核 / 梦魇海龙。勾了哪个，进哪个本就播报。

**每条技能有两个独立的勾**：

| 勾选项 | 作用 |
|---|---|
| 技能释放 | Boss 一放技能就念，比如「六芒星」 |
| 冷却 / 血量预警 | 到点或到血线时念，比如「六芒星已好」「马上拉冰」 |

⚠️ **这两勾是分开的**。只勾了「技能释放」，就只会念技能名，不会念"已好"和血量预警——很多人以为"语音没生效"，其实是只勾了一半。

**分组默认是折叠的**。点组名可以展开，展开后才能看到组里的每一条。**折叠不等于关闭**，组标题右边的「全选」按组生效。

**音色**：Vivi2.0（清脆女声）/ 小何2.0（清晰女声），可调音量。换音色后建议点一下「试听当前音色与音量」确认能出声。

**几个要知道的限制**：

- 只在**实时统计**时播报，回放历史抓包不播
- 「已好」是**按技能释放时间推算的预估提醒**，不是服务端真实冷却，Boss 可能提前或延后放
- 只播报**已经识别出目标**的情况（比如"注意影舞者点名"），职业未知时不猜

## 五、支持哪些副本

| 副本 | 播报 | 悬浮窗倒计时 | 只显示当前分组 |
|---|---|---|---|
| 黑龙巢穴（经典 / 123） | ✅ | ✅ | — |
| 黑龙巢穴（硬核） | ✅ | ✅ | ✅ |
| 沙龙（硬核） | ✅ | ✅ | ✅ |
| 梦魇龙巢 / 梦魇海龙 | ✅ | ✅ | ✅ |
| **试炼梦境·海龙萨芬特拉**（活动副本） | ✅ | ✅ | ✅ |

> 「只显示当前分组」是给**同时有两组 Boss 在打**的副本用的：只显示你正在攻击的那一只的技能，别组的倒计时和播报会被压掉。梦魇龙巢第一关的天启／狮蝎就是这种场面。

> **试炼梦境·海龙萨芬特拉和梦魇海龙是同一套东西**——打的内容、Boss、技能都一样，只是入口不同。
> 所以它**共用「梦魇海龙」那一组播报和悬浮窗设置**，不需要单独再勾一遍。

**梦魇龙巢还有个特殊机制：换边（置换）**

打天启/狮蝎时要和另一组的角色互换位置。工具会：

- 每次换边时播「换边完成」
- 在下次换边前 **30 秒**播「准备换边，倒计时30秒」，悬浮窗上同时显示 124 秒倒计时

> 这个倒计时是按 **124 秒固定周期**推的，换边本身是手动触发的，"归零"只代表"差不多该换下一次了"。

## 六、快捷键

| 快捷键 | 作用 |
|---|---|
| `Alt + F12` | 一键开始：统计 + 悬浮窗 |
| `Alt + F11` | 一键结束：停统计 + 关悬浮窗 |

都可以在 **设置 → 快捷键与窗口** 里改。

---

## 七、回放抓包

统计面板可以把一份 `.dpscap` 抓包文件当录像放，用来复盘或验证播报。

**回放能验证**：技能时间点、倒计时长度、语音文案、换边周期。

**回放验证不了**：「只播报当前分组」（语音里那个）和「只显示当前分组」（悬浮窗里那个）。因为回放里没有"玩家在打谁"的信息，工具不知道你当时的目标，所以不会过滤——两边的技能会混在一起念，这是正常的。

## 八、常见问题

**抓不到数据 / 一直显示未连接**

1. 是不是用管理员身份启动的（看窗口标题栏有没有异常提示）
2. 有没有点「开始统计」
3. 设置页里 Npcap 是否显示已识别；没识别就手动指定 `wpcap.dll`
4. 用了加速器的话，换一种加速模式再试（本地代理模式可能抓不到）

**语音没声音**

1. 先点一次「试听当前音色与音量」，第一次播放需要解锁浏览器音频
2. 检查「语音播报」总开关、巢穴勾选、以及每条技能下面的两个勾
3. 确认是**实时统计**中，不是回放

**列表里找不到某个技能**

老存档不会自动补上后来新增的技能项。在对应分组里点「全选」，或者手动勾一下就有了。

**悬浮窗没出来**

- `Alt+F12` 重新拉起
- 「悬浮窗设置」里确认勾了「Buff 状态 / Debuff 状态」和「启用 Boss 技能倒计时」

**界面白屏 / 卡住**

关掉进程重新打开。仍然不行就看看是不是杀毒软件拦了 `msedgewebview2.exe` 或工具本体。

## 九、数据存在哪

| 内容 | 位置 |
|---|---|
| 界面设置（语音、悬浮窗版式、快捷键） | 本机应用数据目录，重新解压或换版本都不影响 |
| 调试记录（可选，默认关闭） | `文档\DragonNestDpsCapture\debug_records\` |
| 抓包临时文件 | 系统临时目录，统计结束自动清理 |

**调试记录**在 **设置 → 调试记录** 里开：开启后会保留每轮的原始抓包 `.dpscap` 和观测日志，适合遇到问题时抓一份发给开发者定位。平时保持关闭就行。

---

## 十、注意

- 工具只**读取**网络包，不会向游戏进程注入任何东西，也不会修改游戏文件
- 运行期间**不联网**：没有上报、没有账号、没有云端同步
- 请自行确认所在环境的使用规则，风险自负
